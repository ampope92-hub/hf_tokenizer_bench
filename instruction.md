We need a tokenizer benchmark tool. There's a Cargo project stub at /app/repo, the hf_tokenize binary, which already lists the tokenizers crate as a dependency and right now it just prints an empty report. Finish it so it runs Hugging Face tokenizers over a folder of cases and prints the analysis. The box has network so it can pull tokenizers straight from the Hub.

The exact report format is written up in /app/repo/SPEC.md. Follow it to the letter, we'll diff your output against ours. You run the tool as bash /app/repo/run.sh <cases-dir>, which builds the release binary and runs it with that directory. It has to print the report as a single line of JSON on stdout, and running it twice on the same input has to give byte identical output. We've put sample cases at /app/cases, and we point the same binary at other case folders in this format, so it needs to read whatever directory its handed rather than assuming the sample.

We collect /app/repo/src, /app/repo/Cargo.toml, /app/repo/Cargo.lock, /app/repo/.cargo/ and /app/repo/run.sh along with /app/cases, and we build and run the project ourselves from a clean checkout, so leave all of that in place and buildable. Cargo.lock is pinned to versions that resolve against the toolchain in the image and .cargo/config.toml sets the resolver that keeps it that way, so if you change either of them the build's still got to work.
